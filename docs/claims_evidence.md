# Claims and evidence

> Phase 5 (2026-11-22). One row per claim the project makes. Every number comes from a query output in `outputs/` or from `notebooks/03_statistical_tests.ipynb` (summary in `outputs/phase5/test_results.csv`). Test IDs (T1 …) refer to that summary. "Holm p" = p-value adjusted for the 15 tests run (docs/metrics.md, metric 27). Rows marked ESTIMATE rest on stated assumptions and show association, not proven cause.

**Verdict scale:** *supported* = significant after Holm with a meaningful effect size, or a direct count; *not supported* = the data contradict the claim; *inconclusive* = the data cannot settle it either way; *partly supported* = part of the claim holds, part does not.

## What this means for the "two levers" story
- **Lever 1, re-engagement:** supported. Repeat buying is about 2% almost regardless of the first-order experience (claims 5–7). The main signal is category (claim 11), which suggests targeting re-engagement by what customers bought.
- **Lever 2, delivery reliability for reputation:** supported. Lateness is linked to a large rise in bad reviews (claims 1–2), concentrated in RJ/SP and the SP → RJ route (claim 3) and in cross-state shipments (claim 8).
